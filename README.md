# Folder Locker

Folder Locker is a Windows desktop application for protecting private folders.

## Features

* Password-protected access
* Hide folders
* Unhide folders
* Lock folders
* Unlock folders
* Activity logging
* Database integrity verification
* Backup and recovery support

## Requirements

* Windows 10 or Windows 11
* Python 3.12+

## Installation

Install dependencies:

pip install -r requirements.txt

Run:

python folder_locker_gui.py

## Project Structure

folder_locker_gui.py - GUI application

main.py - Backend logic

Assets/ - Icons and images
